# CS330CompGraphicAndVisualization

1. How do I approach designing software?
   For my approach, my design process was to start by envisioning the scene as a whole. After that I would look at each object in the scene, and think about what basic shapes match parts of the complex object the best. After that I would gather all my textures for each object. Then I would position each shape where I needed it to be, setup all the sizes and textures, then I would keep moving and shaping until it looked correct. Lastly, I got all my of my object materials ready for lighting, I set up the lighting position and levels. Then I applied the materials to each object giving the object its reflective properties. I think some new design skills I picked up was being able to design and visual UI/Visual Components in 3D. I've done most web design at work so visualizing things in 3D is not necessary but can really help make pages do some cool stuff. So I think that will be something I try to implement in future things I build.

2. How do I approach developing programs?
   I think a great approach I picked up with designing visual components is to make a plan for the whole visual component so a web page, scene, etc. Then plan out the various sections. Once you have planned it out, starting building each section and putting them roughly where they should go, and doing roughly what they should do. Once the whole thing is done you can begin to iterate through each section slowly fine tuning it until its exactly as you envision or close.
